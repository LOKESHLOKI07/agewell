# AgeWell Mobile Navigation

## Primary Tabs (Bottom Navigation)
The app utilizes a standard five-tab navigation layout for the primary experience:
1. **Home**
2. **Services**
3. **Health**
4. **Community**
5. **Profile**

## Home Screen Hierarchy
The Home UI follows a strict functional hierarchy designed to answer immediate user questions ("Am I safe?", "What is happening today?", "Who is helping me?", "What services can I use?", "What is my membership usage?"):

1. **Emergency:** Persistent, easily accessible safe/emergency action.
2. **Today's Care:** Immediate itinerary and day overview.
3. **Quick Services:** Fast-path to commonly requested capabilities.
4. **Live Care Associate Tracking:** Active module that appears when a service is ongoing.
5. **Membership Usage:** Real-time quota and benefit consumption indicators.
6. **Explore AgeWell / Community / Life:** Secondary engagement features.
7. **Bottom Navigation:** The five primary tabs mentioned above.

## Secondary Navigation Flows
- **Service Request Flow:** Service Menu -> Service Details -> Scheduling -> Confirmation.
- **Health Management:** Categories (Medication, Docs, Tests) -> Detail view -> Upload/Edit Document.
- **Emergency Flow:** Trigger Emergency -> Select Specific Emergency Type -> Confirm (to avoid misdials) -> Ongoing Case & Location Sharing screen.
- **Profile / Identity:** Switch Modes (Senior <-> Family), Privacy & Consent Settings, Notification Preferences.
